# Compiled V8.33 2B/2C probes

This directory contains 107 native KTRANS V8.33 Build 25 `.pc` outputs, one for each `B2Cnnnn.KL` in `KL/V8.33/Probes/`. Read `KL/V8.33/Probes/00_READ_FIRST.md`, `PROBE_INDEX.csv`, and `PROBE_MANIFEST.json` for the purpose, pairing, hashes, and raw verified `2B/2C` prolog bytes. `Logs/` holds each KTRANS result. The PCs are controlled compiler outputs, not decompilations of existing FANUC programs.
